Recursos de Acessibilidade

🔡

Tamanho da Fonte

Use os botões A+, A e A- na barra superior para ajustar o tamanho do texto.

⊙

Alto Contraste

Ative o modo de alto contraste para melhorar a visibilidade do conteúdo.

♿

VLibras — Libras

O site conta com o widget VLibras para tradução de conteúdo em Língua Brasileira de Sinais (Libras).

Clique no ícone VLibras no canto inferior direito da tela.

⌨️

Navegação por Teclado

Todas as funcionalidades do site são acessíveis via teclado. Use Tab para navegar e Enter para ativar elementos.

🔗

Ir para o Conteúdo

Pressione Tab ao abrir a página para ver o link "Ir para o conteúdo principal" e pular a navegação.

📱

Responsividade

O site é totalmente responsivo e funciona em dispositivos móveis, tablets e computadores.

Conformidade com WCAG 2.1

Este site foi desenvolvido seguindo as diretrizes de acessibilidade para conteúdo web WCAG 2.1 nível AA, em conformidade com a Lei Brasileira de Inclusão (Lei nº 13.146/2015) e o Decreto nº 5.296/2004.
